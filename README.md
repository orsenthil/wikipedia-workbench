# Wikipedia Workbench

A personal Wikipedia workbench for [User:Phoe6](https://en.wikipedia.org/wiki/User:Phoe6):
trim the watchlist down to a focus list, work on those articles, and track the contributions.

## Run locally

```bash
cp .env.example .env      # fill in the bot password (see below)
uv run editor             # http://127.0.0.1:8000, no app login locally
uv run pytest
```
